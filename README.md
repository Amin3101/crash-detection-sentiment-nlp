# Quera AI Bootcamp — Project 2

Summer 1405 · Accident Detection & Sentiment Analysis

## Overview

This repository contains the solutions for Project 2 of the Quera AI Bootcamp, covering two independent problems:

1. **Accident Detection** — Binary classification of short video clips to detect whether a car accident occurred, using frame extraction and a video-based classifier.
2. **Sentiment Analysis** — Analysis and modeling of Amazon electronics product reviews, including exploratory data analysis, aspect-based satisfaction scoring, and a 1–5 sentiment prediction model.
